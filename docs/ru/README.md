## Руководство по CLI

Консольная утилита `utka` позволяет администрировать комплекс напрямую с сервера без веб-интерфейса:

### Список команд

| Команда | Описание |
|---|---|
| `utka status` | Проверка подключения к PostgreSQL, статуса демона и gRPC-сокета Xray. |
| `utka sync` | Принудительная синхронизация активных пользователей из базы данных в память Xray на всех узлах. |
| `utka user list` | Табличный вывод всех подписок, объёма потреблённого трафика и активных инбаундов. |
| `utka user add <имя>` | Создание нового пользователя с клиентскими инбаундами по умолчанию и генерацией ссылки. |
| `utka user get <имя\|токен>` | Детальная информация о пользователе, VLESS-ссылки и QR-код прямо в терминале. |
| `utka user delete <имя\|токен>` | Удаление ключей пользователя со всех узлов Xray и удаление записей из базы данных. |

## Настройка клиентских приложений

Utka отдаёт универсальные динамические подписки для всех современных клиентов:

- **Clash Verge Rev / Mihomo Party (ПК)**: Вставьте ссылку подписки в раздел «Профили». Режим работы: «Правило» (Rule).
- **Hiddify (Android / iOS / ПК)**: Нажмите «Новый профиль» $\rightarrow$ «Добавить из буфера обмена».
- **Karing / ClashMi (iOS / Android)**: Нажмите «Добавить профиль» и вставьте ссылку вида `/s/:token`.
- **Sing-box**: Используйте эндпоинт `/api/sub/:token` для прямой загрузки конфигурации JSON.
