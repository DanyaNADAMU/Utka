# Walkthrough: Веб-страница ссылки-подписки в браузере

Реализована полноценная, удобная и визуально привлекательная веб-страница (клиентский портал) для пользователей при переходе по ссылке подписки в браузере.

## Изменения

### 1. `src/lib/subPageTemplate.ts` [NEW]
- Создан модуль генерации автономной HTML-страницы с современным дизайном (тёмная тема, адаптивность для смартфонов и широкоформатных ПК).
- Включает генерацию векторных SVG QR-кодов прямо на стороне сервера с помощью пакета `qrcode`.
- **Локализация (RU / EN)**:
  - Интерактивный переключатель языков (`RU` / `EN`) в шапке страницы.
  - Мгновенная смена языка всех текстовых элементов (заголовки, трафик, кнопки, уведомления, инструкции к приложениям) без перезагрузки страницы.
  - Автоматическое сохранение выбора языка в `localStorage` и поддержка параметра URL (`?lang=en` / `?lang=ru`).
- **Широкоформатный полноэкранный макет**:
  - Ширина контейнера расширена до `1400px` для полного использования пространства монитора.
  - Двухколоночный макет для ПК-экранов (`min-width: 1024px`):
    - Левая колонка: Трафик, Клиентские Deep-Link кнопки, Пошаговые инструкции.
    - Правая колонка: Карточки доступных локаций и серверов.
  - Сетка серверов и приложений автоматически адаптируется и заполняет всю доступную ширину.
- **Интерактивные блоки**:
  - **Шапка и статус подписки**: Имя подписки, имя пользователя, дата обновления и индикатор активности.
  - **Карточка использования трафика**: Учет загрузки, отдачи и суммарного объема (Upload, Download, Total).
  - **Кнопки быстрой интеграции**: `hiddify://`, `clash://`, `sing-box://`, `sub://`, копирование ссылки и QR-код.
  - **Список серверов/локаций**: Карточки всех доступных серверов с кнопками VLESS и QR-кодами.
  - **Инструкции по настройке**: Вкладки для Android, iOS, Windows, macOS со пошаговыми подсказками.

### 2. `src/app/[...slug]/route.ts` [MODIFY]
- Интеллектуальное автоопределение запросов (`Accept: text/html` vs VPN-клиенты).
- Автоматическая очистка неактуальных инбаундов из базы данных.
