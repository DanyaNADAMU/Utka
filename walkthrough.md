# Walkthrough: Веб-страница ссылки-подписки в браузере

Реализована полноценная, удобная и визуально привлекательная веб-страница (клиентский портал) для пользователей при переходе по ссылке подписки в браузере.

## Изменения

### 1. Автоопределение операционной системы пользователя
- Реализована функция `detectAndSetOS()`, которая автоматически при загрузке страницы определяет ОС клиента (Android, iOS/iPadOS, Windows/Mac/Linux) и делает активной соответствующую вкладку с инструкциями.

### 2. Поддержка Тёмной и Светлой темы
- Внедрена единая переменная система CSS-токенов (`:root` и `html.light`).
- В шапку рядом с переключателем языка добавлена кнопка выбора темы (`🌙` / `☀️`).
- Тема автоматически сохраняется в `localStorage` (`sub_theme`) и учитывает системные предпочтения устройства (`prefers-color-scheme`).

### 3. Исправление мобильной шапки и имя клиента
- Запрещен перенос переключателей в шапке на новую строку (`flex-wrap: nowrap`). Шрифт и отступы подстраиваются под мобильные экраны.
- Удалена лишняя плашка `Пользователь: ...`. Имя клиента выводится единожды крупным заголовочным шрифтом строго по центру страницы.

### 4. Обновление названия Clash в Android-инструкции
- Название кликабельной ссылки в тексте первого шага изменено с «Clash Android» на **Clash** (ссылка сохранена).

## Верификация
- Успешно выполнен билд проекта (`npm run build`).
- Проведена проверка валидности генерируемого HTML/JS кода.
- Выполнен деплой на мастер-сервер `moscow-nadamudash`.
