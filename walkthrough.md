# Walkthrough: Веб-страница ссылки-подписки в браузере

Реализована полноценная, удобная и визуально привлекательная веб-страница (клиентский портал) для пользователей при переходе по ссылке подписки в браузере.

## Изменения

### 1. `src/lib/subPageTemplate.ts` [NEW]
- Создан модуль генерации автономной HTML-страницы с современным дизайном (тёмная тема, адаптивность для смартфонов и ПК).
- Включает генерацию векторных SVG QR-кодов прямо на стороне сервера с помощью пакета `qrcode`.
- Содержит интерактивные блоки:
  - **Шапка и статус подписки**: Имя подписки, имя пользователя, дата обновления и индикатор активности.
  - **Карточка использования трафика**: Учет загрузки, отдачи и суммарного объема (Upload, Download, Total) с удобным форматированием байт.
  - **Кнопки быстрой интеграции (Deep Links)**:
    - `hiddify://` (Hiddify Next)
    - `clash://` (Clash / Clash Verge)
    - `sing-box://` (Sing-Box)
    - `sub://` (Shadowrocket)
    - Скопировать ссылку подписки в 1 клик.
    - Всплывающее модальное окно с QR-кодом всей подписки.
  - **Список серверов/локаций**: Карточки всех доступных серверов с кнопками скопировать VLESS-ссылку и открыть персональный QR-код локации.
  - **Инструкции по настройке**: Вкладки для Android, iOS, Windows, macOS со пошаговыми подсказками.

### 2. `src/app/[...slug]/route.ts` [MODIFY]
- Добавлено интеллектуальное автоопределение запросов:
  - Запросы с заголовком `Accept: text/html` от стандартных браузеров открывают красочную веб-страницу.
  - Запросы от VPN-клиентов (Hiddify, Clash, Shadowrocket, v2rayN, Sing-Box, curl и др.) или с параметром `?raw=true` / `.yaml` продолжают получать техническую подписку (Base64 или YAML).
- Добавлена очистка устаревших/удаленных инбаундов:
  - При каждом запросе подписки проверяются актуальные конфиги активных нод (`node.xrayConfig`).
  - Инбаунды, удаленные с нод или относящиеся к неактивным нодам, автоматически вычищаются из базы данных и не отображаются ни в браузере, ни в подписках.
